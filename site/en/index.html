01 / architecture

A Linux workstation,
without carrying a laptop.

03 / first steps

From download to
your first shell.

The recommended path uses the published ARM64 binary from releases. You do not need to install Go to get started.

Read the full installation guide →
TERMUX
# in Termux
pkg update
pkg install -y curl coreutils

# download the ARM64 release
BASE_URL="https://github.com/ericklucioh/mobdesk/releases/latest/download"
curl -fL -o mobdesk "$BASE_URL/mobdesk-linux-arm64"
chmod 0755 mobdesk
./mobdesk setup
Setup creates the Ubuntu workspace, configures SSH and installs the launcher.
!

04 / transparency

Built for development.
Not production.

Mobdesk is experimental and device compatibility is still expanding. Android may suspend processes, PRoot uses the phone's kernel and performance depends on your hardware.
