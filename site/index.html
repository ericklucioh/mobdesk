03 / primeiros passos

Do download ao
primeiro shell.

O caminho recomendado usa o binário ARM64 publicado nas releases. Não é necessário instalar Go para começar.

Ver instalação completa →
TERMUX
# no Termux
pkg update
pkg install -y curl coreutils

# baixe o release ARM64
BASE_URL="https://github.com/ericklucioh/mobdesk/releases/latest/download"
curl -fL -o mobdesk "$BASE_URL/mobdesk-linux-arm64"
chmod 0755 mobdesk
./mobdesk setup
O setup instala os pacotes necessários no Termux, cria o workspace persistente, configura o SSH e instala o launcher.
!

04 / transparência

Feito para desenvolvimento.
Não para produção.

Mobdesk é experimental e a validação em aparelhos Android ainda está sendo ampliada. Ele exige ARM64 e Termux de fonte confiável; mantenha espaço para o Termux, seus projetos e ferramentas instaladas. O Android pode suspender processos, e o SSH deve ficar apenas em redes confiáveis.

ARM64Arquitetura necessária
ARMAZENAMENTOTermux, projetos e ferramentas
LANSSH apenas em rede confiável
