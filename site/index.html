01 / arquitetura

Uma workstation Linux,
sem carregar um notebook.

O Android continua sendo o host. O Termux controla o ambiente e o PRoot-Distro mantém um Ubuntu persistente para seus projetos e ferramentas.

03 / primeiros passos

Do download ao
primeiro shell.

O caminho recomendado usa o binário ARM64 publicado nas releases. Não é necessário instalar Go para começar.

Ver instalação completa →
TERMUX
# no Termux
pkg update
pkg install -y curl coreutils

# baixe o release ARM64
BASE_URL="https://github.com/ericklucioh/mobdesk/releases/latest/download"
curl -fL -o mobdesk "$BASE_URL/mobdesk-linux-arm64"
chmod 0755 mobdesk
./mobdesk setup
O setup cria o workspace Ubuntu, configura o SSH e instala o launcher.
!

04 / transparência

Feito para desenvolvimento.
Não para produção.

Mobdesk é experimental e a compatibilidade ainda está sendo ampliada. O Android pode suspender processos, o PRoot usa o kernel do aparelho e o desempenho depende do seu hardware.

ARM64Arquitetura necessária
~1,5 GBInstalação base do Ubuntu
LANSSH apenas em rede confiável
